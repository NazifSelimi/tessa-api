# Tessa Release 2 Asset Shortlist

## Rule

Do not download or republish brand imagery from search results. Use this list to
request approved source files from Fanola/RR Line/Oro Therapy or to select
Tessa-owned content. Every final asset needs an owner, source URL, packaging
revision, and approval status.

## First Campaign: Fanola Blonde and Tone

The first storefront collection should be built around the current Fanola
Wonder No Yellow two-step routine. It is a clear client story and a natural
bridge to professional colour maintenance:

1. Cleanse: Wonder No Yellow Shampoo.
2. Tone and nourish: Wonder No Yellow Mask.
3. Protect technical hair: Fiber Fix, only where the approved professional
   protocol applies.

Official reference pages:

- https://www.fanola.it/en/consumer-tips/wonder-no-yellow
- https://www.fanola.it/en/product/wonder-no-yellow-shampoo-9500215
- https://www.fanola.it/en/product/wonder-no-yellow-mask-9500216
- https://www.fanola.it/en/product/fiber-fix-no-pre-bond-fixer-9500406

## Tessa-Owned Instagram Content

Use Instagram for proof and education, not as the sole product-image source.
Good content types are:

- Real blonde, highlight, colour-correction, or post-bleach transformations.
- An educator explaining a product step.
- A salon-service result with the exact products and line known.
- Hands, hair, and texture in use; avoid a hero that is only a bottle on a
  salon counter.

Existing relevant examples identified during review:

- Fiber Fix damaged-hair protocol reel:
  https://www.instagram.com/tessabeauty.institute/reel/Db84Y1NqxMJ/
- Oro Therapy Gold Perm protocol reel:
  https://www.instagram.com/tessabeauty.institute/reel/Db349iWK5la/

Before reuse, record the performer/client consent status and the product line
shown. Do not claim that an image represents Wonder No Yellow unless that line
was actually used.

## Oro Therapy and RR Line

These are not homepage campaign candidates until current packaging is verified.
Request a current distributor/manufacturer kit with:

- Transparent packshots for every sellable SKU.
- Current line hero/campaign images.
- Product line sheet with EAN, size, and technical/retail status.
- Current technical sheet for colour/activator compatibility.
- Written permission for ecommerce and social use in North Macedonia.

Do not use the existing old-generation Oro Therapy or RR Line images for the
new release. They may remain as temporary legacy product images until replaced,
but should not be used in a campaign header.

## Extensions, Brushes, Tools, and Fluids

Do not source these from generic web search. Tessa needs a sellable inventory
sheet first:

| Field | Required before publishing |
| --- | --- |
| Product name and brand | Yes |
| SKU/EAN | Yes |
| Size, shade, length, or tool specification | Yes |
| Retail/professional visibility | Yes |
| Price and stock | Yes |
| Current packshot | Yes |
| Care/pairing product | Extensions only |
| Source and asset permission | Yes |

Rename each internal `Fluid` into a customer-useful role before showing it in
the storefront: smoothing fluid, repair leave-in, glossing fluid, or scalp
fluid.

## Asset Folder Contract

Store approved source files outside public product storage, grouped by brand
and line. Each asset delivery should include:

```text
brand/
  line/
    originals/
    packshots/
    campaign/
    technical-sheets/
    asset-register.csv
```

The asset register must include: filename, product/line, source URL, licence or
approval owner, packaging revision, intended use, and approval date.

## Definition of Ready

The Blonde and Tone campaign can go live when it has one approved Tessa-owned
result image, current shampoo/mask packshots, one approved Fanola campaign
image, matched product data in Tessa, and reviewed client-facing copy.
